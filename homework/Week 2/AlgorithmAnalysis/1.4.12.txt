1. Ý tưởng thuật toán (Kỹ thuật hai con trỏ - Two Pointers):
- Vì cả hai mảng a[] và b[] đã được sắp xếp tăng dần, ta sử dụng hai con trỏ `i` (duyệt mảng a) và `j` (duyệt mảng b), đều khởi tạo từ 0.
- So sánh a[i] và b[j]:
  + Nếu a[i] < b[j]: Phần tử a[i] nhỏ hơn nên không thể xuất hiện trong b[j...]. Tăng i++.
  + Nếu a[i] > b[j]: Phần tử b[j] nhỏ hơn nên không thể xuất hiện trong a[i...]. Tăng j++.
  + Nếu a[i] == b[j]: Đã tìm thấy giá trị chung!
    * In giá trị a[i].
    * Để tránh in lặp lại nếu có các phần tử trùng lặp trong cùng mảng, ta tăng cả i++ và j++. (Có thể bỏ qua các phần tử trùng lặp tiếp theo nếu chỉ muốn in danh sách các giá trị chung duy nhất).
- Quá trình dừng lại khi một trong hai con trỏ đi hết mảng (`i >= N` hoặc `j >= N`).

2. Code Java chi tiết:

import edu.princeton.cs.algs4.StdOut;

public class PrintIntersection {

    // In ra các phần tử xuất hiện ở cả hai mảng a và b (đã sắp xếp)
    public static void printCommonElements(int[] a, int[] b) {
        int i = 0;
        int j = 0;
        int n1 = a.length;
        int n2 = b.length;

        StdOut.print("Cac gia tri xuat hien o ca hai chuoi: ");

        while (i < n1 && j < n2) {
            if (a[i] < b[j]) {
                i++;
            } else if (a[i] > b[j]) {
                j++;
            } else {
                // a[i] == b[j]
                StdOut.print(a[i] + " ");

                int currentVal = a[i];
                // Bỏ qua các phần tử trùng lặp trong cả hai mảng để in giá trị duy nhất (unique)
                while (i < n1 && a[i] == currentVal) i++;
                while (j < n2 && b[j] == currentVal) j++;
            }
        }
        StdOut.println();
    }

    public static void main(String[] args) {
        // Ví dụ 2 mảng kích thước N đã được sắp xếp
        int[] a = {1, 2, 4, 6, 8, 10, 10, 12};
        int[] b = {2, 5, 6, 9, 10, 10, 15, 20};

        printCommonElements(a, b);
        // Kết quả mong đợi: 2 6 10
    }
}

3. Phân tích độ phức tạp:
- Thời gian chạy (Time Complexity): Sau mỗi bước của vòng lặp `while`, ít nhất một trong hai con trỏ `i` hoặc `j` sẽ tăng lên 1. Tổng số bước lặp tối đa là `n1 + n2 = 2N`. Do đó, thời gian chạy tuyến tính O(N) trong trường hợp tồi nhất.
- Bộ nhớ bổ sung (Space Complexity): O(1) do chỉ sử dụng các biến con trỏ đơn giản.
